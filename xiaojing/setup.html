密钥用 Windows 自带的加密存在本机，只有你这个 Windows 账号能解开，不会写进任何明文文件。已经设过的密钥留空就是不改。

NapCat 那边要怎么配

  1. 装好 NapCat，登录一个 QQ 小号（自动收发消息有被封号的风险）。
  2. 在 NapCat 后台的「网络配置」里新建 HTTP 服务器：
    地址127.0.0.1端口3020Token自己设一串，填到左边消息格式array
  3. 再新建 HTTP 客户端（上报 / webhook）：
    URLhttp://127.0.0.1:5311/Token再设一串，填到左边"签名"消息格式array
  4. 不用开 WebSocket。保存后回到这里点「保存并启动」。

端口别用 4300–4310，QQ 自己会占。
