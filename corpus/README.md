# 语料：语气参考

这些是给小鲸看的说话例子，第 5 步会用来训练 RBT3 场景分类，并且每一圈按场景挑 2–3 段放进提示。在那之前，可以先挑几段最好的抄进 `persona.md` 的「语气例子」里。

## 怎么写

每个场景一个文件。每条例子三段，用 `---` 隔开：

```
## 情境
朋友：今天面试又挂了

## 好的回复
啊……抱抱。哪家啊，说出来我陪你骂两句

## 人机味的回复
很抱歉听到这个消息。面试失败是成长的一部分，建议你总结经验，下次一定能成功。

---
```

- **情境**：对方说了什么。需要前情就多写两句，用「朋友：」「阿北：」这种前缀。
- **好的回复**：你希望她怎么回。可以分几条，一行一条。
- **人机味的回复**：最像客服、最像 AI 的那种回法。训练"人机味打分"要用，写得越典型越好。

## 先攒多少

每个场景先写 20 条。每个文件开头那条是格式示例，可以删掉。
